= Rules checked by veraPDF for each PDF/A standard

*veraPDF version used: 1.30.2* (Gradle property `verapdfVersion` in `build.gradle`). With another version of veraPDF rules can be added or removed; then this list has to be generated again.

This list comes from the validation profiles of veraPDF (`org/verapdf/pdfa/validation/PDFA-*.xml` in `core-jakarta`). Each row is one rule (clause of the standard and the number of the test). The description is the original text of the profile. Messages of the program have the form `<standard> <clause>-<test>`.

Many rules apply to several standards (for example all rules of 1b also apply to 1a). Each standard is therefore listed completely.
